# Project Groundtruth

A standalone interactive checklist for the Project Groundtruth AI & Computer Vision Engineering curriculum.

## Deploy with GitHub Pages

1. Create a public repository named `project-groundtruth` (or choose another name).
2. Upload `index.html`, `README.md`, and `.github/workflows/pages.yml` to the repository root.
3. In **Settings → Pages**, set the source to **GitHub Actions** if it is not already selected.
4. Open the **Actions** tab and wait for the `Deploy to GitHub Pages` workflow to finish.
5. The site will be available at `https://<your-github-username>.github.io/<repository-name>/`.

Checklist state is saved in the browser's local storage. Use the built-in JSON export/import to transfer progress between browsers/devices.
